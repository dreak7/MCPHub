### 2.3 八大工具详细 Schema 与返回结构定义 (Tool Deep Dive)

#### 1. `stock_lookup`（标的代码与名称语义智能检索）
- **功能**：输入股票简称、拼音首字母或代码，智能检索出标准 6 位 A 股代码、5 位港股代码及交易所代码。内置纯数字代码三轨正主保全机制与代码精确命中检测。
- **核心契约字段**：
  - `exact_match` (bool)：目标市场内是否精准命中了该代码或正规全称的上市证券；
  - `matched_code` (str | null)：精准命中的证券代码；
  - `未命中说明` (str)：当 `exact_match == false` 时注入，说明返回列表仅为语义关联候选（非正主），指引核对代码；
  - `候选为空说明` (str)：当搜索词在指定市场范围内未匹配到任何实体时注入。

#### 2. `market_context`（国内交易日历与市场时钟感知）
- **功能**：获取东八区北京时间所处的 A 股市场实时交易状态及基准交易日。
- **返回字段字典**：
  - `current_cst_time` (str)：当前东八区北京时间格式 `YYYY-MM-DD HH:MM:SS`；
  - `market_status` (str)：时段枚举（`call_auction_morning` 盘前集合竞价、`trading_morning` 早盘中、`lunch_break` 午间休市、`trading_afternoon` 午后盘中、`closed_today` 今日已收盘、`weekend_closed` 周末休市）；
  - `is_trading_time` (bool)：当前时刻交易所是否正处于连续竞价撮合中；
  - `reference_trading_date` (str)：基准交易日。

#### 3. `stock_quotes`（实时盘口微观高频行情与估值指标）
- **功能**：查询指定股票的五档委托买卖盘口、现价、涨跌幅、换手率、量比、总市值与专业估值指标。
- **返回结构核心字段字典**：
  - `股票名称`, `现价`, `涨跌幅_pct`, `涨跌额_元`, `昨收`, `今开`, `最高价`, `最低价`, `日内振幅_pct`（已彻底清除 `最高`、`最低`、`涨跌额`、`振幅_pct` 镜像别名，杜绝整表遍历求和双计）；
  - `成交量_手` (港股为 `成交量_股`，整数型), `成交额_元` (港股为 `成交额_港元`)；
  - `换手率_pct`, `量比`, `更新时间`, `结算货币`；

  - `top_holders`: 交付真实总股本校准后的 `持股占总股本比例_pct` 与 `持股占流通A股比例_pct` 双口径字段，附带分母说明；明确指出在 A+H 两地上市标的（如 601658 邮储银行）或控股股东持股数超过境内纯 A 股流通盘时，`持股占流通A股比例_pct` 允许且完全可能 >100%；港股持股 5% 以上主要股东增设顶层【`最新申报日期`】与【`最新申报时效提示`】，行级挂载【`时效风险提示`】；分母依据股份类别动态区分 A 股与 H 股分母；空记录返回【未收录（上游未采集或待更新）】；
  - `unlocks`: 唯一规范交付 formatted_tables.unlock_schedule（已彻底切除 table0 杜绝同哈希重复表与双计）。限售股解禁计划与自算闭合铁律。同一表中【解禁股数_万股】与【占总股本比例_pct】严密闭合。**引用铁律：只信【解禁股数_万股】（可与多阶段明细相邻行差分核对），占比一律基于当前法定总股本自算**（`解禁股数 ÷ 法定总股本`）；上游 T014 原值保留为【上游申报批次占比_pct】仅代表历史申报批次口径；【解禁后参考流通股本_万股】消解口径歧义；多阶段解禁明细中【解禁股数_万股】严格取当期解禁值（CURRENT_FREE_SHARES），严禁取解禁后累计流通股本；若已过法定承诺解禁日但上游仍标“未实施”，已自适应注入进度纠偏说明。

#### 7. `stock_screener`（国内 A 股自然语言智能选股）
- **功能**：自然语言选股条件筛选。
- **入参别名无缝兼容**：支持 `message`、`query` 与 `condition` 自由互通；
- **市场范围红线**：固定覆盖中国 A 股全市场（沪深北）。输入包含港股意图（如“港股 腾讯”）时，自动注入 `market_scope: A股`、`is_hk_intent: true` 与权威 `warning` 警示，引导调用适用工具。

#### 8. `stock_news`（个股最新资讯与重大公告）
- **功能**：获取指定个股最近发布的突发新闻资讯、重大公告、研报与媒体快讯。
- **防污染拦截与研报属性标注**：
  - 针对不存在或无效代码前置抛错拦截，绝不使用泛化检索返回他股资讯；
  - 自动识别以“券商名：观点”命名的券商研究团队署名行业研报，注入 `内容属性说明: 券商行业研报观点` 标签，防止将券商对外发表的行业观点误判为上市公司自身日常经营公告；
  - 增加他股 IPO 上市挂牌快讯拦截机制，杜绝同业对比正文引发的无关个股挂牌快讯误召回；
  - 聚合新闻与重大公告列表严格按时间戳倒序（reverse=True）排列交付，确保列表首条即为最新鲜发布（修复 P3-1）。

### 4.3 港股财报标准化字段映射与计算口径

1. **金额单位统一为【元】**：东方财富港股三张表原始数值为元，网关严格保持元级标准，杜绝以万元、百万元为单位引发的倍数级财务幻觉；
2. **法定申报原币 (Reporting Currency) 动态治理与逆向还原**：
   - 东方财富港股三张表作为主力数据源，其原生记账币种包含人民币 (CNY)、港元 (HKD) 与美元 (USD)；
   - 绝大多数中资港股企业（如腾讯控股、美团等）在法定公告中均以人民币作为记账本位币，网关在 `indicators` 宽表中自动校准为 `CNY`；
   - 针对以美元作为法定申报币种的美港两地上市标的（如 02026 小马智行、09868 小鹏汽车等），网关底层动态探测法定记账币种为 `USD`，并通过逐期将【东财指标表折算后人民币营收 ÷ 损益表法定美元原币营收】动态反解出各期官方真实折算汇率（零硬编码字典，自适应未来任何新财报与汇率波动），将指标宽表（`indicators`）与现金流表（`cashflow`）全量逆向还原为真实法定原币 USD，并挂载【法定申报原币校准说明】与【跨表币种勾稽说明】，实现三大表与核心指标原币 100% 勾稽闭环；
3. **单季度前驱缓冲区做差推算与财年首季守护 (`period_type="quarter"`)**：
   - 当调用单季度拆分时，网关动态从前驱报告期调取对比池：
     $$\text{Q3 单季营业额} = \text{前三季度累计 (5,518 亿)} - \text{H1 半年度累计 (3,615 亿)} = 1,902.76 \text{ 亿}$$
   - **财年首季守护 (Fiscal Year Q1 Guard)**：针对特殊会计财年标的（如阿里巴巴 09988 财年为 04-01 至次年 03-31）或财年第一季度（`DATE_TYPE_CODE == '003'`，如阿里 06-30 为新财年一季报），当期累计值即为单季真实值，网关强行阻断向上一财年年报（03-31 累计）做差，彻底消除净利润负 929 亿等荒谬偏差；
4. **动态自适应现金桥闭合恒等式**：
   - **口径 A（现金流净额不含汇率，如腾讯 00700、复星医药 02196）**：
     $$\text{期末现金} = \text{期初现金} + \text{经营净额} + \text{投资净额} + \text{筹资净额} + \text{汇率变动对现金及现金等价物的影响}$$
   - **口径 B（现金流净额已含汇率，如中国太保 02601）**：
     $$\text{期末现金} = \text{期初现金} + \text{经营活动现金流量净额 (已含汇率)}$$
   - 网关在返回字典中提供现场自适应判定的 `现金桥闭合说明`，严禁机械写死一条公式造成 12.94 亿等假差额；
5. **报表类型与披露时效差异说明**：
   - 网关全量接入东方财富原生 `DATE_TYPE_CODE` 映射字典（`001: 年报, 002: 中报, 003: 一季报, 004: 三季报`），彻底消除特殊结账期标的现金流表报表类型滞后一个季度的标签错位；
   - 港股绝大多数非 A+H 纯港股标的仅披露半年报与年报，中资 A+H 股（如太保 02601、复星 02196）依据中国证监会法规强制披露 Q1 与 Q3。
6. **港股金融财报框架与准则双轨制契约对齐**：
   - **双重金融机构嗅探**：港股引擎设立完整的金融机构实体与报表特征识别器，针对银行（如 03968 招商银行、00005 汇丰控股）、保险（如 02318 中国平安）、证券及金融控股标的，自适应注入 `is_financial: True` 与 `accounting_standard: "国际/香港财务报告准则 (银行 / 保险 / 证券 / 金融控股)"`；一般非金融企业标定为 `is_financial: False` 与 `accounting_standard: "国际财务报告准则 (IFRS) / 香港财务报告准则 (HKFRS) - 一般工商业"`，与 A 股财报契约 100% 对称；
   - **资产负债表核算说明**：金融标的资产负债表不严格区分流动与非流动划分，以资产与负债流动性高低排列，网关自动注入 `资产负债表核算说明` 并在发生准则不平衡时核算 `金融资产负债不平衡自陈差额`；
   - **利润表与现金流纪律说明**：利润表自适应注入 `利润表加总纪律说明`，指引利息净收入、手续费及佣金净收入与投资收益为核心收益来源；现金流量表自适应注入 `现金流量表加总纪律说明`，指引存贷款变动与三大活动净额分析。
